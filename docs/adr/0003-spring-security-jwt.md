# ADR-0003：使用 Spring Security 与 JWT 实现无状态鉴权

- 状态：Accepted
- 日期：2026-11-08

## 背景

项目是前后端分离的 Vue3 + Spring Boot 应用。需要区分学生和管理员权限，并避免在服务端维护会话。

## 决策

- 使用 Spring Security 6 的过滤器链。
- 登录成功后签发 JWT，前端在 `Authorization: Bearer <token>` 中携带。
- 密码使用 BCrypt 哈希存储。
- JWT 中包含用户 ID、用户名和角色。
- 后端使用 `ROLE_STUDENT` 和 `ROLE_ADMIN` 做接口级授权。
- 服务端不保存登录会话。

## 结果

优点：

- 与前后端分离部署方式匹配。
- 可以展示认证过滤器、密码哈希和角色授权。
- 不依赖服务端 Session，水平扩展简单。

代价：

- MVP 没有服务端主动注销和令牌撤销列表。
- 令牌泄露后在过期前仍然有效。
- JWT 密钥必须通过环境变量或外部配置管理，不能写死在生产配置中。

## 备选方案

- Session：实现简单，但前后端分离和跨域部署时需要额外的会话配置。
- 简单拦截器：代码少，但缺少标准过滤器链和细粒度授权。
